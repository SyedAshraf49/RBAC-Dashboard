  RENDER DEPLOYMENT - QUICK START COMMANDS
═══════════════════════════════════════════════════════════════

📦 STEP 1: CREATE POSTGRESQL DATABASE
───────────────────────────────────────────────────────────────
1. Go to: https://dashboard.render.com
2. Click: "New +" → "PostgreSQL"
3. Settings:
   Name: rbac-dashboard-db
   Database: reminder_dashboard
   Region: Singapore (or closest)
   Plan: Free
4. Click: "Create Database"
5. WAIT for database to initialize (1-2 minutes)
6. COPY the "Internal Database URL" (you'll need it below)

═══════════════════════════════════════════════════════════════

🌐 STEP 2: CREATE WEB SERVICE
───────────────────────────────────────────────────────────────
1. Click: "New +" → "Web Service"
2. Connect repository: SyedAshraf49/RBAC-Dashboard
3. Settings:
   Name: rbac-dashboard
   Region: Singapore (same as database)
   Branch: main
   Runtime: Python 3

   Build Command (COPY THIS):
   ┌─────────────────────────────────────────────────────────┐
   │ pip install -r backend/requirements.txt                 │
   └─────────────────────────────────────────────────────────┘

   Start Command (COPY THIS):
   ┌─────────────────────────────────────────────────────────┐
   │ cd backend && gunicorn --bind 0.0.0.0:$PORT app:app     │
   └─────────────────────────────────────────────────────────┘

   Plan: Free

═══════════════════════════════════════════════════════════════

🔧 STEP 3: ADD ENVIRONMENT VARIABLES
───────────────────────────────────────────────────────────────
Click "Advanced" then add these environment variables:

Variable 1:
   Key: DATABASE_URL
   Value: <PASTE THE INTERNAL DATABASE URL FROM STEP 1>

Variable 2:
   Key: SECRET_KEY
   Value: <Generate random string at https://djecrety.ir/>
   Example: 8k9JdL2mN5pQ7rS1tU3vW4xY6zA0bC2dE4fG6hI8jK0

Variable 3:
   Key: FLASK_ENV
   Value: production

Variable 4:
   Key: SMTP_SERVER
   Value: smtp.gmail.com

Variable 5:
   Key: SMTP_PORT
   Value: 587

Variable 6:
   Key: SMTP_EMAIL
   Value: <your-email@gmail.com>

Variable 7:
   Key: SMTP_PASSWORD
   Value: <your-gmail-app-password>

   📧 To get Gmail App Password:
   - Go to: myaccount.google.com/security
   - Enable 2-Step Verification
   - Go to: App passwords
   - Generate password for "Mail"
   - Copy the 16-character password

═══════════════════════════════════════════════════════════════

🚀 STEP 4: DEPLOY
───────────────────────────────────────────────────────────────
1. Click: "Create Web Service"
2. Wait 5-10 minutes for deployment
3. Monitor logs for any errors
4. Once complete, you'll get a URL like:
   https://rbac-dashboard.onrender.com
